Quick phrases

  

    
Type the shortcut in any box and press Space, Tab or Enter to expand it. Shortcuts can be anything without spaces. Starting them with a dot (like .ihc) stops them expanding by accident. Put {date} or {time} in a phrase to insert today's date or the current time automatically.

Save to OneDrive

  

    

      
1. Save the app with your settings (recommended)

      
This saves a new copy of PathReport.html with all your sites, templates and quick phrases inside it. Save it into your OneDrive folder and replace the old file. Every computer that opens it will then have your latest setup. In Edge or Chrome you can choose the OneDrive folder directly. Other browsers save it to Downloads, and you move it into OneDrive yourself.

      

      

    

    

      
2. Backup or transfer settings only

      
Export your settings as a small .json file, or load one in. This is handy for sharing templates with a colleague.

      

        
        
        
      

    

    

      
3. GitHub: app updates and template sync (no patient data)

      
When you open a newer PathReport file on this computer, it uploads its code to your GitHub repository (never any data), and Azure redeploys the online app a few minutes later. Uses a GitHub fine-grained token that can only change that one repository; it is kept only in this browser.

      

        

        

        

      

      

      
      
      

      

    

    

      
Shared workstation tools

      
The browser also keeps a copy of your settings, but never report text. On a shared hospital computer you can remove it when you leave.
